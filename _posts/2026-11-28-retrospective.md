## 1. 지금까지의 활동

### 1.1. 보안 분야 입문

1학년 때 해킹동아리 EVISION에서 웹 해킹, 리버싱, 포너블에 대한 기초 지식을 학습하고 실습을 진행하였다.

웹 해킹에서는 SQL Injection을 활용하여 취약한 웹 서버를 공격하고 취약점을 수정하는 실습을 진행하였다. 리버싱에서는 IDA를 활용하여 Dreamhack의 기초 문제를 풀고 동아리 내 미니 CTF에 참여하였다. 포너블에서는 버퍼 오버플로우의 개념과 공격 원리를 학습하였다.

또한 컴퓨터 중앙동아리 ECC의 프론트엔드 트랙에서 HTML, CSS, JavaScript의 기초 문법을 공부하고 직접 웹페이지를 구성하는 실습을 진행하였다.

### 1.2. 개발 프로젝트

웹사이트의 동작 방식과 서버의 구조에 대한 궁금증을 바탕으로 JSON 형식의 API 명세와 Python 코드를 비교하는 DocCodeCheckerMCP 서버를 개발하였다. 이 과정에서 AI를 활용하여 코드를 작성하고 서버를 구현하며 배포까지 경험하였다.

Summer Sprint Camp에서는 팀원들과 함께 웹 개발 및 보안 실습을 진행하였다. 웹사이트의 기능을 구현하는 것뿐만 아니라 취약점이 발생하는 원인과 이를 보완하는 방법에 대해서도 공부하였다.

### 1.3. CTF 대회 참여

SEGMENT CTF에 팀원들과 함께 참여하여 암호학과 스테가노그래피 문제를 분석하고 해결하였다.

평소 접하지 않았던 유형의 문제를 풀면서 새로운 개념을 공부하고 이를 문제 해결에 적용하는 경험을 할 수 있었다.

### 1.4. 블록체인 및 보안 연구

블록체인 응용 과목을 수강하면서 Python을 활용한 채굴 프로그램 구현, 블록체인 데이터 변조 및 재채굴 실험, NFT 발행 등의 실습을 진행하였다.

또한 Qubit Finance의 스마트 컨트랙트 보안 사고를 주제로 보고서를 작성하고 발표하였다. 실제 보안 사고의 발생 원인과 공격 과정, 피해 규모, 대응 및 개선 방안을 조사하였다.

이외에도 보안 관련 학술 논문을 읽고 연구의 문제의식, 핵심 아이디어, 연구 방법 및 실험 결과를 정리하는 활동을 진행하였다.

### 1.5. 현재 진행 중인 학습

현재는 임베디드 보안 분야에 관심을 가지고 Dreamhack을 활용하여 관련 기초 지식을 학습하고 있다.

ARM 아키텍처와 어셈블리어, 레지스터, 스택 등의 개념을 공부하고 있으며 학습한 내용을 정리하며 이해도를 높이고자 노력하고 있다.

## 2. 지금까지의 활동에서 부족했던 부분

### 2.1. 기초 지식 부족

지금까지 다양한 보안 분야를 접하였지만 각각의 기술을 깊이 있게 이해하기 위한 기초 지식은 아직 부족하다고 생각한다.

특히 1학년 때 리버싱 문제를 풀면서 어셈블리어에 대한 지식이 부족하여 AI의 도움을 많이 받았다. 문제를 해결하더라도 코드가 어떤 원리로 동작하는지 스스로 이해하는 데에는 어려움이 있었다.

보안 기술을 제대로 이해하기 위해서는 컴퓨터 구조, 운영체제, 네트워크 등 기본적인 지식을 충분히 쌓을 필요가 있다고 생각한다.

### 2.2. AI 의존도

MCP 서버 개발이나 보안 실습을 진행하면서 AI의 도움을 많이 받았다. AI를 활용하여 새로운 기술을 접하고 문제를 해결할 수 있었지만 작성된 코드와 문제 해결 과정을 스스로 이해하고 분석하는 능력은 더 기를 필요가 있다고 생각한다.

앞으로는 AI를 통해 얻은 답을 그대로 사용하는 것이 아니라 해당 코드가 왜 필요한지 어떤 원리로 동작하는지 직접 확인하는 과정을 거치고자 한다.

### 2.3. 체계적인 학습 방향 부족

웹 해킹, 리버싱, 포너블, 블록체인 등 다양한 분야를 경험하였지만 특정 분야에 대해 체계적으로 깊이 있는 학습을 진행한 경험은 부족하다고 생각한다.

관심 있는 분야를 공부하는 것뿐만 아니라 어떤 지식이 필요한지 파악하고 학습 순서와 구체적인 목표를 설정하는 과정이 필요하다.

또한 학습한 내용을 실습이나 프로젝트로 연결하여 실제로 활용할 수 있는 능력을 기르고 싶다.

### 2.4. 활동 기록 부족

이번에 지금까지의 활동을 블로그에 정리하면서 이전에 진행했던 활동의 세부적인 과정이나 배운 내용을 다시 확인하기 어려운 부분이 있었다.

활동의 결과물뿐만 아니라 진행 과정에서 발생한 문제와 해결 방법, 새롭게 알게 된 내용도 기록하는 것이 중요하다고 생각한다.

## 3. 앞으로의 개선 방향

우선 현재 관심을 가지고 있는 임베디드 보안 분야를 중심으로 체계적인 학습 계획을 세우고자 한다.

컴퓨터 구조와 운영체제에 대한 기초 지식을 쌓고 ARM 아키텍처와 어셈블리어에 대한 이해를 높인 뒤 펌웨어 분석까지 학습 범위를 넓혀갈 계획이다.

Dreamhack을 활용하여 이론과 실습을 병행하고 문제를 풀 때 바로 풀이를 참고하기보다는 스스로 분석하고 해결 방법을 고민하는 시간을 늘리고자 한다. AI를 활용하는 경우에도 답을 얻는 것에 그치지 않고 문제 해결 과정과 코드의 동작 원리를 충분히 이해하도록 노력할 것이다.

또한 학습한 내용을 바탕으로 직접 프로젝트를 구상하고 구현하여 하나의 완성된 결과물을 만드는 경험을 쌓고 싶다.

앞으로 진행하는 활동은 블로그와 GitHub에 꾸준히 기록하고 이전에 학습한 내용을 다시 확인하면서 부족한 부분을 보완할 예정이다.

## 4. 마무리

지금까지 다양한 활동을 진행하면서 여러 보안 분야를 경험할 수 있었지만 각각의 활동에서 배운 내용을 충분히 이해하고 활용하는 능력은 더 기를 필요가 있다고 생각한다.

앞으로 나이츠프론티어 활동을 통해 단순히 많은 활동을 수행하는 것보다 하나의 활동을 하더라도 그 과정에서 확실하게 배우고 이를 다음 학습에 활용하고 싶다.

최종적으로는 스스로 학습 방향을 설정하고 보안 문제를 분석하여 해결할 수 있는 능력을 기르는 것이 목표이다.
